# 🌐 Awesome Network Tools

Free online network diagnostic and security tools.

## DNS & Domain
- [DNS Lookup](https://nettool1.com/tools/dns-lookup/) - Query DNS records
- [WHOIS Lookup](https://nettool1.com/tools/whois-lookup/) - Domain information
- [Reverse DNS](https://nettool1.com/tools/reverse-dns-lookup/) - IP to hostname

## Network Testing
- [Ping Test](https://nettool1.com/tools/ping-test/) - Test connectivity
- [Speed Test](https://nettool1.com/tools/speed-test/) - Internet speed test
- [Port Scanner](https://nettool1.com/tools/port-scanner/) - Check open ports

## Security
- [SSL Checker](https://nettool1.com/tools/ssl-checker/) - Verify SSL certificates
- [IP Blacklist Check](https://nettool1.com/tools/ip-blacklist-checker/) - Check IP reputation
- [HTTP Headers](https://nettool1.com/tools/http-headers/) - Inspect HTTP headers

## Web Analysis
- [Source Code Viewer](https://dl-kit.com/tools/source-code-viewer/) - View page source
- [Website Screenshot](https://dl-kit.com/tools/website-screenshot/) - Capture screenshots
